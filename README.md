# ЕГЭ Тренажер 1561 — Telegram Mini App

Интерактивное веб-приложение (Telegram Mini App) для экспресс-подготовки к ЕГЭ по русскому языку (задания 4 и 5: орфоэпический словник и словарик паронимов ФИПИ).

Разработано в рамках индивидуального проекта ученика 10 «Т» класса ГБОУ Школа № 1561 (Корпус 11) Сабивчака Арсентия.

## Функционал
* 🎯 **Орфоэпия (Задание 4):** база из 40+ сложных слов с неповторяющейся колодой заданий.
* 📚 **Паронимы (Задание 5):** контекстные примеры употребления паронимов.
* ⚡ **Мгновенный разбор:** цитирование нормативных правил ФИПИ при ошибке.
* 🔁 **Интервальное повторение:** модуль «Повторить ошибки» в конце раунда.
* 📱 **Адаптивный дизайн:** полная интеграция с цветовой темой и Haptic Feedback Telegram.
